# Little Oak Montessori Website Prototype

Original responsive multi-page Montessori school website informed by the supplied Pravesh Montessori School reference.

Public: Home, Home 02, About + Montessori Philosophy, Programs + Curriculum, Facilities, Gallery, Admissions, Contact.

Parent portal: Login, Dashboard, My Child, Activities + Attendance, Reports + Progress, Calendar + Documents, Fees + Payments + Messages, Profile.

The Pravesh pattern adapted here is: utility strip, compact school navigation, strong hero, feature highlights, school/about story, academics, campus/gallery, people, admissions and portal calls-to-action, and a substantial footer. Branding and copy are original.

Demo data, contact details, images and authentication must be replaced before production.
